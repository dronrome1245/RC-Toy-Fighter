# 🚀 Наши полёты

Здесь будем записывать, как самолёт учится летать.

Для каждого полёта запишем:

- дату;
- где летали;
- была ли сильная погода или ветер;
- что получилось хорошо;
- что было трудно;
- что изменим перед следующим полётом.

## Для ребёнка

После каждого полёта ответь на три вопроса:

1. Что сегодня получилось?
2. Что удивило?
3. Что хотим попробовать в следующий раз?

Можно добавлять рисунки и фотографии.
