# 👨 Технические заметки для папы

Эта папка нужна для информации, которая ребёнку пока не нужна: точных размеров, характеристик электроники, расчётов, маркировок, ссылок на товары и технических решений.

## Важное правило

Технические заметки не должны быть единственным описанием решения.

Если здесь принято важное решение, которое влияет на сборку, его результат нужно перенести в соответствующий детский раздел простыми словами.

Пример:

Технический вывод:

> Выбран сервопривод массой 5 г с рабочим напряжением 4,8–6 В.

В детской инструкции должно появиться:

> Мы выбрали маленький лёгкий моторчик для руля. Он достаточно лёгкий, поэтому самолёту будет проще лететь.

## Здесь можно хранить

- точные характеристики деталей;
- расчёт массы и центра тяжести;
- параметры аккумулятора;
- электрическую схему;
- настройки аппаратуры;
- ссылки на документацию;
- причины выбора конкретных компонентов.
