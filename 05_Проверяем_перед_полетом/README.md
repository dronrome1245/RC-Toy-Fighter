# ✅ Проверяем перед полётом

Самолёт сначала учится быть безопасным на земле.

До первого полёта мы проверим:

- всё ли крепко держится;
- правильно ли двигаются рули;
- не мешают ли тяги друг другу;
- хорошо ли закреплён аккумулятор;
- правильно ли расположен центр тяжести;
- слушается ли самолёт пульта;
- останавливается ли мотор по команде;
- не находится ли человек рядом с вращающимся винтом.

## Главное правило

⚠️ Проверки с мотором проводит взрослый.

👦 Ребёнок может помогать по чек-листу и говорить: «проверено» после каждого безопасного пункта.
