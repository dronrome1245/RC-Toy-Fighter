# RC Toy Fighter

Проект переделки пенопластового самолёта-запускалки 35 см в радиоуправляемую микромодель.

## Рабочий вход

**Взрослому:** [`00_РУКОВОДСТВО_ДЛЯ_ВЗРОСЛОГО.md`](00_РУКОВОДСТВО_ДЛЯ_ВЗРОСЛОГО.md)

**Текущее состояние:** [`STATUS.md`](STATUS.md)

**Любой нейросети / новому чату:** [`00_AI_START_HERE.md`](00_AI_START_HERE.md)

## Текущий принцип

Сначала получаем и измеряем фактический 35-см самолёт, затем выбираем электронику по реальной массе и геометрии.

Прежняя конфигурация для планера около 68 см (`2204 / ESC 20A / 2S / 5030`) отменена.

До измерений не утверждаем конкретные мотор, аккумулятор, ESC/приёмник и сервы.

## Работа с ребёнком

Репозиторий предназначен прежде всего для взрослого. Ребёнку не требуется читать документацию.

Педагогическая цель сохраняется: ребёнок участвует через безопасные практические действия — измерения, взвешивание, выбор, прогноз результата, простые проверки и фиксацию завершённых этапов.

Визуальные материалы для совместного просмотра находятся в [`08_Картинки_для_понимания`](08_Картинки_для_понимания/).
