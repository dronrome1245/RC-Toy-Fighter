## Текущий принцип

Заказан конкретный пенопластовый самолёт 35 см, Ozon product id `5530158944`.

Сначала получаем, фотографируем, взвешиваем, измеряем и проверяем его как планер. Только после этого утверждаем конкретную полётную электронику.

Старая конфигурация для планера около 68 см (`2204 / ESC 20A / 2S / 5030`) отменена.
