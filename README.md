# RC Toy Fighter

Мы с папой делаем игрушечный самолёт, который сможет летать и управляться с пульта.

Главное правило этого проекта: **каждый файл должен быть понятен ребёнку 6 лет**.

Если появляется сложное слово, рядом должно быть простое объяснение: что это такое, зачем оно нужно и как это выглядит.

## Как будем работать

1. Сначала разберём, что сделано в исходном видео.
2. Потом поймём, какие детали нужны.
3. Нарисуем простые схемы.
4. Соберём самолёт по маленьким шагам.
5. Проверим всё на земле.
6. Только потом попробуем летать.

## Правило безопасности

Резать, паять, заряжать аккумуляторы, подключать мотор и делать другие опасные операции может только взрослый. Ребёнок участвует в безопасных этапах: выборе, разметке, сборке простых деталей, проверке по картинкам и управлении под присмотром взрослого.
