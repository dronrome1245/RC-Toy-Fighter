# ✈️ RC Toy Fighter

Мы с папой делаем игрушечный самолёт, который сможет летать и управляться с пульта.

## 👦 Сначала открой это

➡️ **[00_НАЧНИ_ЗДЕСЬ.md](00_НАЧНИ_ЗДЕСЬ.md)**

Это главная страница проекта для совместной работы с ребёнком.

## Главное правило проекта

**Каждый файл должен быть понятен ребёнку 6 лет.**

Если появляется сложное слово, рядом должно быть простое объяснение:

- что это такое;
- зачем это нужно самолёту;
- как это выглядит или что делает.

Точное правило для всех будущих изменений записано в [`AGENTS.md`](AGENTS.md).

## Наш путь

1. [`01_Что_мы_строим`](01_Что_мы_строим/) — знакомимся с самолётом.
2. [`02_Наши_детали`](02_Наши_детали/) — собираем список деталей.
3. [`03_Как_это_работает`](03_Как_это_работает/) — разбираемся, как всё устроено.
4. [`04_Собираем_по_шагам`](04_Собираем_по_шагам/) — собираем по одному действию.
5. [`05_Проверяем_перед_полетом`](05_Проверяем_перед_полетом/) — проверяем безопасность и работу самолёта.
6. [`06_Наши_полеты`](06_Наши_полеты/) — записываем результаты полётов.
7. [`90_Для_папы`](90_Для_папы/) — точные технические данные, которые не должны мешать детской инструкции.

Текущий этап: [`STATUS.md`](STATUS.md).

## Как будем работать

1. Разберём, что сделано в исходном видео.
2. Поймём, какие детали нужны.
3. Нарисуем простые схемы.
4. Соберём самолёт по маленьким шагам.
5. Проверим всё на земле.
6. Только потом попробуем летать.

## ⚠️ Безопасность

Резать, паять, заряжать аккумуляторы, подключать мотор и выполнять другие потенциально опасные операции может только взрослый.

Ребёнок участвует в безопасных этапах: выборе деталей, изучении устройства самолёта, простых измерениях и разметке, проверках по картинкам, ведении журнала и управлении под присмотром взрослого.
