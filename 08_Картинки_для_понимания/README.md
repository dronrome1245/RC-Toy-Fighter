# 🖼 Картинки для понимания

Эта папка нужна, чтобы **меньше читать и больше видеть**.

## 👦 Правило для ребёнка

Если непонятно слово — сначала смотри картинку или схему.

Если после картинки всё ещё непонятно — спрашиваем и рисуем ещё проще.

## Что здесь будет

1. части самолёта;
2. мотор и винт;
3. сервопривод;
4. аккумулятор;
5. пульт;
6. простая схема «кто с кем разговаривает»;
7. фотографии нашего настоящего самолёта после получения;
8. фотографии каждого законченного этапа.

## Главное правило для взрослых и нейросетей

Для ребёнка 6 лет **иллюстрация предпочтительнее длинного абзаца**.

Каждый новый технический этап по возможности сопровождается:

- фотографией;
- простой схемой;
- крупными стрелками;
- подписью «что это»;
- подписью «что делает».

## Внешние картинки

Используем либо:

- собственные фотографии проекта;
- свободно лицензированные изображения;
- официальные страницы производителей как справочные примеры.

Не выдаём фотографию похожей детали за фотографию именно нашей детали.
