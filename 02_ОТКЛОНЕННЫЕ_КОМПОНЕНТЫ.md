# Отклонённые компоненты

Здесь фиксируются конкретные товары, которые были рассмотрены, но не подходят текущей архитектуре проекта.

## SG90 180° — Ozon product id 3075849940

Ссылка: https://www.ozon.ru/product/servoprivod-sg90-180-grad-plastikovyy-reduktor-krutyashchiy-moment-1-2-kg-sm-4-8-v-1-4-kg-sm-6-0-3075849940/

**Статус:** ⛔ НЕ ПОКУПАТЬ ДЛЯ УСТАНОВКИ В САМОЛЁТ.

Причины:

- типичная масса оригинального SG90 — около 9 г;
- питание — 4,8–6 В;
- текущая архитектура микромодели ориентирована на 1S LiPo 3,7–4,2 В;
- 9 г на одну серву слишком много для самолёта 35 см;
- для питания SG90 от 1S потребовался бы дополнительный преобразователь, что ещё увеличит массу и сложность.

Ориентир для нашего самолёта: микросервы примерно 1,7–2 г, совместимые с 1S. Конкретный SKU выбирается после фактического взвешивания донора и выбора схемы управления.

SG90 можно использовать только как отдельную учебную/настольную серву, но не как полётный компонент этой модели.

## Lightning Power LiPo 1S 550 mAh, A30 — Ozon product id 2663935470

Ссылка: https://www.ozon.ru/product/akkumulyatornaya-batareya-lipo-dlya-kvadrokoptera-1s-550mah-lightning-power-razem-a30-2663935470/

**Статус:** ⛔ НЕ ПОКУПАТЬ КАК ОСНОВНОЙ АККУМУЛЯТОР ДЛЯ ТЕКУЩЕЙ 35-СМ МОДЕЛИ ДО ИЗМЕРЕНИЙ.

Что в нём подходит:

- правильная архитектура питания — 1S;
- разъём A30 относится к лёгким 1S micro-RC системам.

Почему не берём сейчас:

- ёмкость 550 mAh для самолёта 35 см, вероятнее всего, избыточна по массе;
- для ориентира: типичный 1S 550 mAh аккумулятор другого производителя имеет массу около 13,5 г, тогда как 1S 300 mAh встречается примерно около 7,7 г;
- для модели этого масштаба разница порядка 5–6 г уже существенна;
- текущий рабочий диапазон для проверки после измерений — примерно 150–300 mAh;
- окончательный разъём должен совпасть с выбранным receiver/ESC; A30 сам по себе не является причиной отказа, но заранее фиксировать его не нужно.

**Важно:** это не означает, что 550 mAh физически никогда не сможет летать. Если после получения самолёта массовый бюджет покажет большой запас и такой аккумулятор потребуется для центровки, его можно будет пересмотреть. Но как базовый вариант для закупки сейчас — нет.
