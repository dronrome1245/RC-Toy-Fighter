# Журнал решений проекта

Этот файл хранит **почему проект стал именно таким**.

Правило: старые записи не удаляются и не переписываются. Если решение изменилось, старая запись получает статус `ЗАМЕНЕНО`, а ниже добавляется новая.

Формат записи:

- дата;
- статус;
- решение;
- причина;
- доказательства/исходные данные;
- последствия;
- что ещё нужно проверить.

---

## D-001 — отдельный репозиторий

**Дата:** 27.08.2026  
**Статус:** ДЕЙСТВУЕТ

**Решение:** проект ведётся только в отдельном репозитории `dronrome1245/RC-Toy-Fighter` и не смешивается с рабочими инженерными проектами пользователя.

**Причина:** семейный учебный проект должен иметь самостоятельный контекст и историю.

## D-002 — ребёнок должен понимать репозиторий

**Дата:** 27.08.2026  
**Статус:** ДЕЙСТВУЕТ

**Решение:** основное содержание файлов должно быть понятно ребёнку 6 лет. Технические детали допускаются отдельным вторым уровнем для взрослого.

**Причина:** проект используется как совместное обучение, а не только как способ получить готовый самолёт.

## D-003 — проект учит доводить дела до конца

**Дата:** 27.08.2026  
**Статус:** ДЕЙСТВУЕТ

**Решение:** проект считается успешным только при прохождении полного цикла: цель → маленькие задачи → выполнение → проверка → исправление → итог → явное закрытие проекта.

**Причина:** одна из целей — сформировать у ребёнка привычку завершать проекты.

## D-004 — предварительный донор около 68 см

**Дата:** 27.08.2026  
**Статус:** ЗАМЕНЕНО решением D-006

**Решение:** первоначально для расчётной оценки был принят распространённый EPP-планер около 68 см.

**Причина:** точный донор ещё не был выбран, нужен был ориентир для изучения идеи из видео.

**Последствие:** предварительно рассматривалась электроника класса 2204 / 2S / 5-дюймовый винт.

**Почему отменено:** фактически пользователь заказал существенно меньший самолёт 35 см.

---

## D-005 — предварительная силовая установка 2204 / 2S

**Дата:** 27.08.2026  
**Статус:** ЗАМЕНЕНО решением D-007

**Решение:** для условного 68-см планера рассматривались мотор 2204 2200–2300KV, ESC 20 A с BEC, LiPo 2S 450–550 mAh и винт 5030.

**Причина:** такая связка имела достаточную тягу для модели того масштаба.

**Почему отменено:** для 35-см микропланера компоненты этого класса дают чрезмерную массу и размеры.

---

## D-006 — выбран фактический донор 35 см

**Дата:** 27.08.2026  
**Статус:** ДЕЙСТВУЕТ

**Решение:** весь проект строится под уже заказанный пользователем товар Ozon: **«Запускалка самолёт пенопластовый 35 см, зелёный»**, карточка товара №5530158944.

**Источник:** ссылка пользователя сохранена в `SOURCES.md`.

**Причина:** это реальный самолёт, который будет физически использоваться в проекте.

**Последствия:** все расчёты и закупки силовой электроники должны быть пересмотрены под микромодель 35 см. Конфигурация для 68 см больше не является действующей.

**Что проверить после получения:**

- фактический размах;
- длину;
- массу голого самолёта;
- материал и толщины;
- геометрию крыла и хвоста;
- наличие заводского балласта;
- положение центра тяжести при хорошем планировании.

## D-007 — электронику выбираем после измерения 35-см донора

**Дата:** 27.08.2026  
**Статус:** ДЕЙСТВУЕТ

**Решение:** до получения и взвешивания самолёта **не утверждать окончательные SKU мотора, аккумулятора, ESC и сервоприводов**.

**Причина:** на масштабе 35 см несколько граммов существенно меняют нагрузку на крыло и поведение модели.

**Доказательства:** найден практический опыт переделки 35-см пенопластовых планеров, где применялись 1S, микросервы 1,7 г и мотор 8520; более крупный brushless 1811 для 35 см был оценён автором переделки как слишком большой и тяжёлый.

**Рабочее направление для проверки после измерений:**

- питание 1S;
- коллекторный мотор класса 8520 с небольшим винтом около 65 мм либо ещё более лёгкая эквивалентная система;
- сервы порядка 1,7 г;
- сверхлёгкий приёмник/приёмник со встроенным brushed ESC;
- минимально необходимое число каналов.

Это **не финальная спецификация**, а направление проектирования.

## D-008 — единый контекст для разных нейросетей

**Дата:** 27.08.2026  
**Статус:** ДЕЙСТВУЕТ

**Решение:** любая нейросеть в новом чате должна начинать с `00_AI_START_HERE.md`, затем читать `STATUS.md`, `DECISIONS.md`, `HISTORY.md`, `SOURCES.md` и `AGENTS.md`.

**Причина:** проект будет продолжаться из разных чатов и разными нейросетями; состояние нельзя хранить только в истории одного диалога.

**Последствие:** после каждого существенного изменения нейросеть обязана синхронизировать текущий статус, решения, историю и источники в репозитории.

---

## D-009 — детская часть проекта строится по принципу «сначала показать»

**Дата:** 27.08.2026  
**Статус:** ДЕЙСТВУЕТ

**Решение:** для материалов, которыми пользуется ребёнок, по возможности сначала давать фотографию, простую схему, пиктограмму или визуальную последовательность, и только затем текстовое объяснение.

**Причина:** ребёнку 6 лет легче понимать устройство и ход проекта через изображение и короткое действие, чем через длинное техническое описание.

**Последствия:**

- создан раздел `08_Картинки_для_понимания`;
- каждый новый крупный технический этап по возможности получает простую визуальную версию;
- после получения настоящего самолёта учебные общие картинки дополняются фотографиями именно нашего экземпляра;
- внешняя картинка похожей детали всегда помечается как пример и не выдаётся за фактически купленную деталь.
