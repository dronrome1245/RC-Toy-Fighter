# 🛒 Покупаем сейчас

Этот список можно использовать **до того, как самолёт приехал**.

Главное правило: сейчас покупаем только то, что точно пригодится независимо от окончательной электроники.

## 👦 Для ребёнка

Сейчас мы собираем **набор исследователя и мастера**.

Мы ещё не покупаем мотор и батарейку самолёта, потому что сначала должны узнать, сколько весит наш самолёт.

---

## ✅ Обязательно

### 1. Весы

- [ ] электронные весы;
- [ ] предел 500–1000 г или больше;
- [ ] шаг показаний **0,1 г**.

👦 **Зачем:** узнаем, сколько весит самолёт и каждая деталь.

### 2. Линейка

- [ ] металлическая линейка 30 см;
- [ ] обычная пластиковая линейка для ребёнка.

👦 **Зачем:** измеряем крыло, хвост и корпус.

### 3. Карандаш и маркер

- [ ] простой карандаш HB;
- [ ] тонкий маркер.

👦 **Зачем:** отмечаем места измерений и будущих деталей.

### 4. Клей для пенопласта

Предпочтительный ориентир:

- [ ] **UHU POR** или другой клей, у которого производитель прямо подтверждает совместимость со вспененным полистиролом/пенопластом.

Официальная страница UHU POR:
https://www.uhu.com/en-en/products/uhu-por-folding-box-50-ml-multi-language

⚠️ До применения на самолёте папа проверяет клей на маленьком незаметном участке.

### 5. Ленты

- [ ] лёгкий прозрачный скотч;
- [ ] тонкий двусторонний скотч;
- [ ] малярный скотч.

Не усиливать самолёт тяжёлой строительной лентой без необходимости: для модели 35 см важен каждый грамм.

### 6. Карбон для будущего усиления

- [ ] карбоновый пруток 1 мм — 1 шт.;
- [ ] карбоновый пруток 2 мм — 1 шт.

Покупаем как материал, но **не вклеиваем**, пока не осмотрим самолёт.

### 7. Мелкие материалы

- [ ] бамбуковые шпажки;
- [ ] зубочистки;
- [ ] тонкая термоусадка;
- [ ] тонкий силиконовый провод — только после окончательного выбора электроники можно уточнить сечение;
- [ ] маленькие пластиковые стяжки.

### 8. Инструмент взрослого

- [ ] макетный нож + запасные лезвия;
- [ ] коврик для резки;
- [ ] пинцет;
- [ ] бокорезы;
- [ ] тонкогубцы;
- [ ] небольшой паяльник с регулировкой температуры;
- [ ] припой;
- [ ] флюс;
- [ ] мультиметр.

👨 Нож, паяльник и электрические работы — только взрослому.

---

## 🟡 Желательно

- [ ] органайзер с ячейками для деталей;
- [ ] карточки/стикеры для доски `НАДО → ДЕЛАЕМ → ГОТОВО`;
- [ ] прозрачная папка А4 для бумажной «Книги самолёта»;
- [ ] LiPo safety bag — понадобится, когда появятся аккумуляторы;
- [ ] USB-кабель/адаптер для будущего авиасимулятора — окончательно выбираем после выбора пульта.

---

# ⛔ Пока НЕ покупать

До получения и измерения самолёта **не заказываем окончательно**:

- мотор;
- винт;
- аккумулятор;
- приёмник;
- ESC;
- конкретные сервоприводы;
- крепление мотора.

Почему: для самолёта 35 см разница даже в несколько граммов может сильно изменить полёт.
