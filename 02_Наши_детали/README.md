# 🧩 Наши детали

Здесь будет список всего, из чего мы собираем самолёт.

Для каждой детали пишем четыре вещи:

1. **Как называется?**
2. **Как выглядит?**
3. **Что делает?**
4. **Она у нас уже есть или её надо найти?**

## Пример

### Сервопривод

👦 **Просто:** маленькая коробочка с рычажком. Она двигает руль самолёта.

👨 **Для папы:** здесь позже укажем размер, массу, напряжение и модель.

Статус: ⚪ пока не выбрали.
